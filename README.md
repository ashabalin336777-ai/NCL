# NeuroCloser — NCL Sales Trainer

**NeuroCloser** — тренажёр переговоров для менеджеров, которые продают электронные компоненты.

Менеджер тренируется с виртуальным клиентом (закупщик, главный инженер или снабженец), учится слышать производственную боль, уверенно презентовать поставку и закрывать на понятный следующий шаг: просчёт BOM, встреча с инженером, NDA или опытная партия.

Интерфейс — тёмный Premium Dark: стеклянные карточки, оранжевый акцент, радар навыков и графики. Один стиль для менеджера, РОПа и оператора платформы.

---

## Кому для чего

| Роль | Для кого | Что умеет |
| --- | --- | --- |
| **Менеджер** | Команда продаж | Тренировки, подсказки Terra, голосовой ввод, радар навыков, разбор Sol, история и стоимость сессий |
| **РОП** | Руководитель отдела | Команда, аналитика прогресса, отчёты для руководства |
| **Разработчик** | Оператор платформы | Баланс проекта, цены на использование ИИ, тексты подсказок, база знаний, пользователи |

Деньги на балансе проекта списываются за каждую тренировку (диалог, подсказки, оценка). Цену для клиента задаёт оператор платформы через наценку к базовому тарифу. Онлайн-оплата — следующий этап.

---

## Как запустить

```bash
cp .env.example .env
# укажите ключ AI в LLM_API_KEY
docker compose up --build
```

Откройте в браузере: **http://localhost:8080**

| Роль | Email | Пароль |
| --- | --- | --- |

| РОП | `admin@ncl.local` | `ChangeMe_Admin_123` |
| Менеджер | `manager1@ncl.local` … `manager3@ncl.local` | `ChangeMe_Manager_123` |

При первом запуске создаётся стартовый баланс проекта (по умолчанию 5000 ₽).
